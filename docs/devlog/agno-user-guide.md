## 📋 使用步骤

### 1. 访问Agno页面
- 打开浏览器访问: http://localhost:8000/ai_agent/agno/
- 使用演示账户登录（如果未登录）

### 2. 选择智能体类型
点击任意一个智能体卡片：

#### 💬 聊天助手
- **功能**: 通用对话智能体
- **适用**: 日常交流和问答
- **特点**: 友好、自然的对话风格

#### 🧠 推理专家  
- **功能**: 具有高级推理能力
- **适用**: 复杂问题分析
- **特点**: 逻辑清晰、步骤详细

#### 👨‍🏫 学习导师
- **功能**: 专业教学智能体
- **适用**: 个性化学习指导
- **特点**: 耐心、循序渐进

### 3. 开始对话
1. 选择智能体后，输入框会激活
2. 在输入框中输入您的消息
3. 点击"发送"按钮或按回车键
4. 等待AI回复

### 4. 切换智能体
- 随时点击其他智能体卡片
- 无需刷新页面
- 对话历史会保留

### 5. 清空对话
- 点击"清空"按钮重置对话
- 智能体选择保持不变

## 🛠️ 故障排除

### 如果遇到问题

1. **检查登录状态**
   - 确保已登录系统
   - 刷新页面重新登录

2. **检查网络连接**
   - 确保能访问OpenAI API
   - 检查防火墙设置

3. **查看控制台日志**
   - 按F12打开开发者工具
   - 查看Console标签页
   - 查找错误信息

4. **重启服务器**
   ```bash
   # 停止服务器 (Ctrl+C)
   # 重新启动
   python manage.py runserver 8000
   ```
