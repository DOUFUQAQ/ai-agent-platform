## 🎯 使用方法

### 步骤1: 访问聊天页面
```
http://127.0.0.1:8000/ai_agent/chat/
```

### 步骤2: 选择模式
1. 点击页面顶部的 "启用 Agno" 按钮
2. 选择一个Agno智能体类型（聊天助手、推理专家或学习导师）
3. 开始对话

### 步骤3: 切换模式
- 点击 "普通模式" 按钮可以切换回原有的AI功能
- 点击 "启用 Agno" 按钮可以重新启用Agno功能
